# FastVideoCut

用 ffmpeg 自动检测黑屏并完成无损裁剪 / 合并的 Windows 桌面工具。
<img width="1919" height="1030" alt="FastVideoCut 主界面" src="https://github.com/user-attachments/assets/937fb68e-2cc2-4ecf-9bfa-f5edc648312f" />

## 功能一览

- **黑屏自动检测**：按 ffmpeg `blackdetect` 标记黑屏区间，片头 / 片尾分段扫描，速度快且不漏边界
- **可视选段**：时间线 + 列表双视图，保留 / 丢弃任意片段，支持人工插入分割点
- **无损导出**：默认 `-c copy` 流复制裁剪与 `concat` 合并，不重编码、不损画质；也可改为重编码导出
- **硬件编码**：自动 / x264 / NVENC / QSV / AMF，硬件不可用时自动回退
- **片段预览**：单击分段即在右侧播放视频和音频，可暂停、拖动、逐段切换
- **多视频合并**：按列表顺序拼成一个文件，合并前自动检查格式一致性
- **界面**：简体中文 / English，深色 / 浅色主题，立即切换
- **源文件只读**：检测与导出都不会修改原视频

## 下载与运行

1. 在 [Releases](https://github.com/dzdhome/FastVideoCut/releases) 下载 `FastVideoCut-x.x.x-win64.zip`，解压后运行 `FastVideoCut.exe`。
2. 需要 Windows 10 / 11（64 位）。
3. 需要 `ffmpeg.exe` 和 `ffprobe.exe`：
   - 程序会自动在自身目录、`bin` 子目录、`PATH` 和常见安装位置中查找；
   - 找不到时会弹窗给出下载地址，请下载后到 **设置 → ffmpeg 目录** 选择包含这两个程序的 `bin` 文件夹。
4. 设置保存在 `%LOCALAPPDATA%\FastVideoCut\settings.ini`。

## 快速上手

1. **添加视频**：工具栏「添加视频」、`Ctrl+O`，或直接把文件 / 文件夹拖进窗口；菜单「文件 → 添加整个文件夹」可批量添加。
2. **自动分析**：按 `F6` 或点「自动分析」，等待日志显示每个视频的黑屏区间。
3. **选择要保留的部分**：在时间线上点选片段（默认整段都保留，被丢弃的片段会变暗）。
4. **导出**：
   - `F7` / 工具栏「导出剪辑」：每个视频按各自的选择单独导出；
   - `F8`：按列表顺序合并成一个文件；
   - 菜单「导出 → 两个都导出」可一次完成两步。
5. 导出完成后可直接打开输出文件夹查看结果。

## 界面说明

### 工具栏

| 按钮 | 作用 |
|---|---|
| 添加视频 | 添加一个或多个视频文件 |
| 移除 / 清空列表 | 从列表移除选中项；清空整个列表（不动磁盘文件） |
| 上移 / 下移 | 调整列表顺序，合并时按此顺序拼接 |
| 自动分析 | 检测未被检测过的视频；分析中再点一次即停止 |
| 导出剪辑 | 按当前选择导出（`F7`） |
| 清理缩略图 | 删除磁盘上的缩略图缓存，下次重新生成 |
| 设置 | 界面、检测参数、导出参数、提示音 |
| 说明 | 打开内置使用说明 |
| 列表 | 在「视频列表（帧流）」和「文件列表」之间切换（`Ctrl+L`） |

### 时间线

- 每个视频左侧显示文件信息和完整编码规格：容器 / 分辨率 / 帧率、编码 / 档次 / 像素格式、音频格式 / 声道 / 采样率。
- 黑屏段带红色斜纹；被丢弃的片段变暗；橙色标记为人工分割点。
- 单击任一分段会在右侧预览窗播放该段。
- 滚轮上下切换视频，`Ctrl+滚轮` 缩放时间线，`Shift+滚轮` 或中键拖动横向平移，`F5` 适应窗口。

### 文件列表

切换出文件列表后可看到：状态、时长、分辨率、规格、黑屏段数量 / 时长、起始 / 结束时间、保留时长、已选段数、文件大小。双击某行会只重新分析该视频。

### 预览窗

- 单击时间线分段即开始播放；切换分段会无缝切换。
- 底栏提供后退 5 秒、前进 5 秒、暂停 / 继续、停止。
- 预览暂停时按钮会变为「插入分割 / 删除分割」，可在当前位置人工切开片段；橙色分割标记可右键删除。

### 日志

分析进度、黑屏位置、导出命令与结果都写在日志里。支持滚轮 / `PgUp` / `PgDn` / `Home` / `End` 滚动、鼠标框选、`Ctrl+C` 复制、`Ctrl+A` 全选。

## 选择操作

| 操作 | 效果 |
|---|---|
| 左键单击片段 | 该片段成为保留区间的起点 |
| 右键单击片段 | 该片段成为保留区间的终点（起点到终点之间全部保留） |
| `Ctrl+左键` | 单独保留 / 取消该片段 |
| 双击片段 | 只保留该片段 |
| 菜单「选择 → 保留主体」`Ctrl+B` | 只保留首末非黑屏段之间的主体 |
| 菜单「选择 → 整段保留」`Ctrl+A` | 恢复为整段保留 |
| 菜单「选择 → 清除选择」`Ctrl+R` | 清除当前选择 |

## 设置

### 路径

- **ffmpeg 目录**：包含 `ffmpeg.exe` 与 `ffprobe.exe` 的文件夹。检测与导出都依赖它。
- **输出目录**：导出文件的保存位置，默认 `%LOCALAPPDATA%\FastVideoCut\output`。

「恢复默认」可把全部设置重置为初始值。

### 界面

- **界面语言**：跟随系统 / 简体中文 / English，切换后立即生效。
- **界面主题**：跟随系统 / 深色 / 浅色，立即生效；标题栏始终跟随 Windows 系统主题。
- **生成视频流缩略图**：默认关闭。关闭时只做黑屏检测，不抽帧、不拼图，速度更快；需要看画面时再打开。

### 黑屏检测

- **最短时长**：短于该值的黑屏不标记（默认 0.10 秒）。
- **像素阈值 `pix_th`** / **比例阈值 `pic_th`**：判定“黑”的阈值，默认 0.10 / 0.98。
- **片头范围 / 片尾范围**：默认只扫描片头、片尾各 180 秒，覆盖绝大多数片头片尾黑屏。
  - 填 `0` 表示该侧完全不扫描；填负数表示该侧整段扫描；两侧都为 `0` 时无法分析。
  - 两个范围重叠或相接时会自动合并成一次扫描。
- **缩略图高**：时间线上缩略图的高度（24–240 像素）。

分析是增量的：`F6` 只检测尚未检测过的视频，`Shift+F6` 重新检测全部，`Ctrl+F6` 只重分析选中的视频。分析过程中按 `Esc` 可立即停止，已完成的结果不会丢失。

### 导出参数

- **导出时重新编码**：默认关闭（无损流复制）。勾选后才按编码器重新压缩。
- **视频编码器**：自动 / x264 / NVENC / QSV / AMF。
  - 「自动」会优先选择可用的硬件编码器（NVENC → QSV → AMF），都不可用时使用 x264。
  - 硬件编码失败时会自动改用 x264 重跑，并在日志中说明原因。
  - 该选项只影响重编码导出；无损导出与它无关。
- **CRF/CQ** 与 **preset**：重编码画质与速度参数，会按所选编码器自动换算对应参数。
- **mp4 输出加 +faststart**：便于网络播放，略微增加导出时间。
- **导出完成后询问是否打开输出文件夹**。

### 提示音

可分别开启「分析完成」和「导出完成」的提示音，只在成功完成时响；勾选时会立即试听。

## 导出与合并

### 无损导出（默认）

- 直接复制原始音视频流，不重新编码，画质与原文件一致，速度很快。
- 选中的相邻片段会合并成一次裁剪，避免多次拼接造成播放闪烁。
- 无损裁剪只能从关键帧开始，程序会自动把切点对齐到前一个关键帧，避免导出文件“开头只有声音、画面延迟出现”。
- 如果切点位置对不齐关键帧，播放时该处附近可能短暂花屏；需要逐帧精确时请改用重编码导出。

### 合并

- 按列表顺序合并；输出文件名按第一个和最后一个视频自动生成，例如 `001` + `010` → `001-010.mp4`，重名时追加 `_1`、`_2`。
- 合并前会检查参与合并的视频在分辨率、编码、帧率、采样率、封装格式、时基等方面是否一致：
  - 全部一致：直接无损合并；
  - 只有封装格式 / 时基 / 流布局不同：弹出「智能合并 / 取消合并 / 强行合并」三个选项；
  - 存在编码、分辨率、帧率等差异：只能取消或强行合并（强行合并可能花屏、断音或时长错误）。
- **智能合并**：先把源文件转封装到临时目录统一格式，再无损拼接，几秒完成，不重编码，源文件不动。
- 重编码导出会先统一格式，因此不做上述检查。

## 命令行

适合批量处理或无界面运行：

```
FastVideoCut.exe [options] <video files...>

  --ffmpeg <dir>      ffmpeg bin 目录（含 ffmpeg.exe / ffprobe.exe）
  --output <dir>      输出目录
  --thumb <px>        时间线缩略图高度（24-240，默认 64）
  --black-min <sec>   blackdetect d=        （默认 0.10）
  --black-pix <val>   blackdetect pix_th=   （默认 0.10）
  --black-pic <val>   blackdetect pic_th=   （默认 0.98）
  --scan-window <sec> 片头片尾各扫 N 秒（默认 180；负数 = 该侧不限制）
  --scan-head <sec>   只扫片头前 N 秒（0 = 不扫片头，负数 = 该侧不限制）
  --scan-tail <sec>   只扫片尾后 N 秒（0 = 不扫片尾，负数 = 该侧不限制）
  --reencode          导出时重编码（默认无损流复制）
  --full-detect       黑屏检测：全文逐帧精确扫描（默认）
  --fast-detect       黑屏检测：关键帧粗扫（快约 6 倍，可能漏检短黑屏）
  --merge-all         合并为一个视频（默认每个输入各出一个）
  --auto-detect       启动后立刻开始黑屏检测
  --auto-export       检测完自动导出
  --nogui             不显示窗口（适合自动化）
  --log <file>        把日志与 ffmpeg 命令追加写入 <file>（UTF-8）
  --quit              任务结束后退出（退出码 0 = 成功，1 = 失败）
```

无头批处理示例：

```powershell
.\FastVideoCut.exe --nogui --auto-export --quit --merge-all `
    --ffmpeg C:\ffmpeg\bin --output D:\out\ --log D:\out\run.log a.mp4 b.mp4
```

> 兼容说明：`--scan-window 0` 沿用旧含义（整段扫描），不是“该侧不扫”。
> 想只扫一侧请用 `--scan-head N --scan-tail 0`。

## 常见问题

**提示找不到 ffmpeg？**
到 [ffmpeg 官网](https://ffmpeg.org/download.html) 下载 Windows 版本，解压后在 **设置 → ffmpeg 目录** 选择 `bin` 文件夹即可。

**硬件编码不可用？**
NVENC / QSV / AMF 依赖显卡驱动和可用会话。选择「自动」时程序会逐个探测并回退到 x264；也可以在日志里查看实际使用的编码器。

**分析速度慢？**
关闭「生成视频流缩略图」，并确认「片头范围 / 片尾范围」只覆盖需要检查的区间（默认各 180 秒）。

**无损导出的开头没有画面 / 切点附近花屏？**
无损模式只能从关键帧起切，程序会自动回退对齐；若仍不满意，请勾选「导出时重新编码」获得逐帧精确的结果。

**合并时提示封装格式 / 时基不一致？**
选择「智能合并」，程序会先转封装统一格式再无损拼接；「强行合并」可能产生时长错误或播放异常。

**切换主题后标题栏没有变化？**
标题栏跟随 Windows 系统主题（设置 → 个性化 → 颜色），不随应用内主题变化。
